# Autolith 0.34.1

Autolith 0.34.1 adds Linux glibc baseline builder support and standalone static musl release archives.

- Releases for Linux x86-64 and aarch64 are packaged on Ubuntu 20.04 (glibc 2.31) for universal glibc distribution compatibility.
- Added standalone static musl release targets (`x86_64-linux-musl` and `aarch64-linux-musl`) for Alpine Linux and minimal container environments.
- Updated installer (`script/install`) with `--musl` option and auto-detection for musl environments.
