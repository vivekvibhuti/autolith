# Autolith 0.33.9

Autolith 0.33.9 adds official release support for ARM Linux (`aarch64-linux`).

- Added `aarch64-linux` platform detection and archive builder support.
- Added GitHub Actions workflow job to package `aarch64-linux` standalone releases.
- Updated release installer and recovery builders for ARM64 Linux systems.
